# Voxa 与 RemotePilot：功能清单和 Rimo 机会

基线为项目本地 `reference` 目录中的 Mac 安装包：Voxa **2.2.1 Build 97** 和 RemotePilot **1.1.5**。参考安装包不随仓库发布。版本取自各自的 `Contents/Info.plist`，功能用同版本发布说明、官方指南和安装包内容交叉核对；这里没有重新启动参考应用做真机测试。仅在本地资料中找到的界面、模块或诊断线索单独标出。

## Voxa 2.2.1

主要依据：[2.2.1 Build 97 发布说明](https://github.com/jinzongma/apple-tv-remote-for-mac/releases/tag/2.2.1-build97)、[对应版本的 Voxa 功能说明](https://github.com/jinzongma/apple-tv-remote-for-mac/blob/2.2.1-build97/VOXA-AI-Guide.md)、[官方项目介绍](https://github.com/jinzongma/apple-tv-remote-for-mac)。本地可复核 `Voxa.app/Contents/Resources` 的说明、本地化文案和 3D 模型，以及分析资料中的输入、语音和预设模块。

| 功能域 | 可确认的用户功能 |
| --- | --- |
| 按键映射 | 点击 3D 遥控器或实体键打开配置，实体按下时模型高亮。支持单键、键盘组合键、左／右鼠标点击和逐键启停；场景中可绑定打开 App；左右修饰键可分别设定，也有调度中心、App 窗口和桌面切换等快捷项。 |
| 按压方式 | 可把短按和按住分配为不同快捷键；长按可维持真正的按下／松开；Siri 键可设双击，电源键有单独的双击配置。配置双击时单击会短暂等待第二次按下。 |
| 特殊按键 | 电源键支持熄屏，双击支持锁屏或睡眠，并有防误触关机设置；电源及点击盘中心有特殊的文本加回车动作。音量键可改为常规映射、滚动或切换麦克风。 |
| 触控板 | 遥控器触控区移动指针、中心点击，可调指针速度，能关闭触控或重新识别触控设备。 |
| 外圈 | 基础版可转圈切换 App；Voice Pro 增加连续／分段滚动、浏览器视频进度及 Codex 任务切换。可调外圈范围和灵敏度，指定按键双击轮换模式；每个场景可覆盖外圈动作与滚轮手感。 |
| 场景 | 按前台 App 自动切换，没有对应场景时使用全局映射。场景从全局映射起步，支持单键动作、按住／双击以及外圈设置的覆盖。 |
| 预设 | 内置网页视频、会议、演示、阅读、音乐和 Codex 六套预设；应用前可查看映射，选择目标 App；可导入 `.voxapreset` 或 JSON，导出场景预设时不包含解锁文本。 |
| macOS 快捷指令 | 有独立页面，支持搜索、刷新、手动执行和显示结果；遥控器直接触发快捷指令属于 Voice Pro，Siri 键不参与这类绑定。 |
| 语音输入 | Voice Pro 可把遥控器变成系统虚拟麦克风，配合豆包、Typeless 等听写软件。Siri 键提供按一下启停或按住说话的联动配置；可配置双击发送，提供输入电平、识别测试、配置引导与故障诊断。 |
| 语音控制 Mac | Voice Pro 的实验功能：自然语言可控制 App、窗口和桌面布局，点击控件、输入文字、滚动，操作媒体、截图、提醒事项、日历和草稿等，亦可调用快捷指令。可将一句话拆成多步，操作遥控器可中断执行。官方说明限简体中文界面，需较新 macOS；进阶理解可用服务额度或自备密钥。 |
| 自定义语音技能 | 用一句触发词绑定一串操作，支持录制、编辑、试运行以及导入技能文本；另有常用词纠错与窗口布局保存／恢复。 |
| 设备与日常使用 | 蓝牙配对、快速连接、设备电量、低电提醒；菜单栏显示连接与语音链路，提供暂停／恢复和修复入口；屏幕顶部胶囊提示动作或故障。支持菜单栏和 Dock 显示、关窗继续运行、登录自启、新手引导，界面含中英日法。 |
| 更新、帮助与授权 | 应用内更新、更新说明、可关闭的使用统计；复制产品说明给外部 AI 助手，用于学习设置或生成预设。基础功能免费，Voice Pro 一次购买，支持激活与换机。 |

语音链路还可在本地语音模块中看到直连与蓝牙抓包两条实现线索；这是采集途径的区别，不等同于两套面向用户的功能。未见 Voxa 2.2.1 提供 iPhone 伴侣、虚拟九键、摇杆面板、云同步映射或 Codex 审批面板的可靠证据。

## RemotePilot 1.1.5

主要依据：[1.1.5 正式版说明](https://github.com/kai-wu-cortex/RemotePilot-Releases/releases/tag/v1.1.5)、[官方发布仓库](https://github.com/kai-wu-cortex/RemotePilot-Releases)、[官方按键、触控与语音文档](https://remotepilot.site/docs)、[配对与安装指南](https://remotepilot.site/guide)。本地可复核 `RemotePilot.app/Contents`、本地化字符串、映射、语音与伴侣模块。

| 功能域 | 可确认的用户功能 |
| --- | --- |
| 按键映射 | 键盘组合键、鼠标、系统动作和媒体动作；可分配滚动、系统键盘、Siri、桌面切换等。支持全局和 App 专属配置、遥控器按键组合，以及单击、双击、长按、按住／松开；官网另列三击和按住连续触发。具体触发因按键、动作和机型而异。 |
| 系统自动化 | 官方文档明确支持按键运行 AppleScript 或 Shell，可用于启动 App、窗口控制和更通用的自动化。未找到与 Voxa 同等的「浏览 macOS 快捷指令库并直接绑定」专门界面。 |
| 遥控器工作室与输入检测 | 本地资料有 3D 模型与工作室 UI、按键检测向导，以及模型灯光、卡片颜色和悬停动画等选项。官方列出 A1962、A2540、A2854，并区分机型的映射、触控和语音能力。 |
| 触控板 | 移动指针、点击、拖拽锁定、带惯性的滚动；可调光标、滚动、触控方向和灵敏度。本地另有光标校准及实验性控件吸附界面、A1962 顶角映射。可关闭触控并保留实体键和语音。 |
| 外圈 | 在滚动、切换应用、移动文字插入光标之间切换，菜单栏用三点指示模式，可配置全局快捷键；官方也把环形操作用于滚动或控轨。没有查到 Voxa 的 Codex 任务外圈模式。 |
| 虚拟九键 | 将支持的遥控器触控面用作 3×3 键盘，输入字母、数字和标点，功能键可重新分配。 |
| 配置管理 | 全局和 App 专属映射、JSON 导入／导出、更新前自动备份；本地文案有可选账户云同步及本机／云端冲突处理。未确认有 Voxa 同款的六套内置预设和应用前预览。 |
| 语音输入 | 可选 Mac 或遥控器麦克风；兼容手机还可提供第三种音源。内置听写胶囊显示实时识别，结束后向原输入框提交；焦点变化时先复制结果。支持虚拟麦克风和 Typeless 等第三方输入方式。 |
| iPhone 遥控与语音 | 需要另装兼容的 iPhone 客户端并与 Mac 配对。在手机上发送实体键相同的动作、移动指针、点击、拖动和滚动；用手机麦克风传音频，可显示波形和文本、校对后发送。 |
| iPhone 控制面板 | 从 Mac 同步 App 列表、图标和运行状态，提供 Launcher 和可自定义 Deck；可排列按钮、摇杆和滑杆作为游戏键盘。手机端可控制音量、亮度、媒体、Escape、调度中心等并查看正在播放的信息；这是远程控制面板，非原生 Touch Bar 镜像。 |
| AI 编程助手看板 | 本地 Mac 伴侣模块和钩子资料有 Claude Code／Codex 会话与远程审批入口；未用同版 iPhone App 验证端到端审批。它处理已有任务的状态或审批，不等同于 Voxa 的自然语言桌面操作。 |
| 设备与日常使用 | 首启配对和授权向导；菜单栏可查看连接、电量和模式，支持中英界面、登录自启、隐藏 Dock 图标、权限修复、功能自检和诊断日志。支持虚拟麦克风组件的安装、修复和卸载。 |
| 更新与授权 | 通过 Sparkle 更新，有 Stable／Nightly 选项；基础功能免费，Pro 一次购买，账户同步授权。 |

**兼容性与证据边界**：1.1.5 修正了部分媒体和音量键映射行为，发布说明仍明确保留 A2540／A2854 电源键可能由系统处理的限制。包内有陀螺仪诊断线索，但[开发者的空鼠说明](https://remotepilot.site/features/a1962-air-mouse)未确认官网 1.1.5 下载包已附带 A1962 空鼠功能。Mac 端发布仓库和包最低版本写的是 macOS 12，但产品文档写 macOS 13+，这里不据此保证 macOS 12 的完整支持。

## 共同功能与差异

| 维度 | 两者都有 | Voxa 的侧重点 | RemotePilot 的侧重点 |
| --- | --- | --- | --- |
| 按键 | 蓝牙输入、键鼠映射、按压方式、按 App 切换 | 3D 模型与编辑卡联动、快捷指令专页、Siri／电源／音量专项配置 | 组合映射、媒体与系统操作、AppleScript／Shell、检测向导 |
| 触控和外圈 | 指针、点击、滚动、外圈切 App | 连续／分段外圈、浏览器视频进度、Codex 任务切换 | 拖拽锁、惯性滚动、文字光标、校准与九键输入 |
| 配置 | 按 App 自动切换和文件导入／导出 | 预设库、应用前预览和按场景覆盖外圈 | 配置备份与可选账户同步 |
| 语音 | 遥控器麦克风、虚拟麦克风、第三方输入法配合 | 语音发出命令，多步操作 Mac，并能录制自定义技能 | 把声音转成文字，输入源更多，手机可预览和校对 |
| AI | 都可以服务 AI 编程工作流 | 转圈切 Codex 任务、语音操作 Mac、复制指南给外部助手 | iPhone 编程会话看板与审批线索；与 Mac 自然语言操作不是同一类 |
| 手机 | 没有足够证据表明两者共有 | 本版本未见 iPhone 伴侣 | 独立 iPhone 客户端，提供触控、Launcher、Deck、游戏键盘与语音 |
| 使用辅助 | 菜单栏、连接状态、电量、授权引导、自启、应用内更新 | 顶部动作和诊断胶囊，免费触控移指针与换 App | 模式指示、输入自检、触控调节与 Stable／Nightly |

## 对 Rimo 的开发建议

Rimo 已提供演示、阅读和视频三套场景预设，以及鼠标点击、滚动、媒体与系统操作、打开 App 等按键动作。单击、双击和长按也已可以分别配置。当前能力与限制见[功能范围](product-scope.md)。仍可考虑以下方向：

1. **点击盘当鼠标**：先验证 A2540 的触点输入可否稳定驱动光标，再考虑中心点击、速度和关闭开关。
2. **外圈手势**：验证触点输入后，可探索用外圈连续滚动、切换 App 或控制视频进度。这与现有的按键触发滚动是不同的输入方式。
3. **本地场景导入与导出**：如需跨 Mac 迁移，须保留全局继承与本地覆盖的区别，并明确导入如何处理已有场景。

语音自动化、手机伴侣和九键输入都需要独立的体验和验证，不属于当前功能范围。
