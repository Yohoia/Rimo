# Rimo 设备界面

本文记录当前 macOS 主应用的设备首页和详情页。共享颜色和控件样式以 [`RimoStyle`](../Rimo/Settings/SettingsView.swift) 为准，设备布局、投影和命中区域分别由 [`MappingView`](../Rimo/Mapping/MappingView.swift) 和 [`RemoteModelView`](../Rimo/Mapping/RemoteModelView.swift) 实现。

## 首页与详情

- 首页用透明 PNG 展示设备，运行时加投影。已连接时可点击进入详情，悬停或键盘聚焦时设备轻微上移。未连接时灰显并禁用设备入口。
- 详情默认展示完整的 3D 遥控器，略向左转，空闲时轻摆并带绿色呼吸光。默认没有热点或标签，也可拖动模型查看。
- 点击模型上的按键后，相机推近按键区，保留所有可配置按键，部分下部握柄裁出画面。场景导航和电量状态向左滑出；仅当前键显示蓝紫色轮廓和短标签。
- 点击模型上的另一个键可切换编辑对象。再次点当前键或标签、点左上角返回，或按 Esc，都会收起动作侧栏并恢复全景。系统开启「减少动态效果」时直接切换状态，浏览时不摇摆或呼吸。

## 动作侧栏

侧栏贴窗口右侧、占窗口宽度三分之一并填满高度。灰色「动作」标题栏里的菜单切换单击、双击和长按；下方是通栏搜索、推荐动作和可折叠的分类。当前动作使用带圆点的实色行，已有但不在推荐列表的动作会置于该列表顶部，便于重新编辑。需配置参数的动作在侧栏内打开，点「动作列表」返回。

侧栏布局参考 Logi Options+ 主应用；Rimo 保留自己的遥控器模型、推近动效和触发方式。参考行为和适配方式见 [Options+ 对照记录](optionsplus-main-findings.md)。

动作顺序为“推荐 → 键盘 → 滚动 → 媒体与音量 → 窗口与桌面 → 系统操作 → 应用与快捷指令 → 其他动作”。推荐根据实体键变化；功能类单键和四向滚动可直接选择；键盘列表按常用按键、修饰键、方向与导航、功能键分段。搜索框采用带完整边框的 48 点输入框，搜索支持动作名和分类名。分类依据、Voxa/RemotePilot 对照和未实现能力见[动作映射清单](action-mapping-catalog.md)。

## 回归检查

1. 以默认窗口（1200 × 720 点）和最小窗口（860 × 600 点）确认全景无标记，选中普通键、方向区、音量键和 Siri 侧键时，描边与模型对齐，最低的键仍完整可见。
2. 验证左右区域不重叠：侧栏贴右且不盖住顶部设备入口；各分组可展开和收起，长列表可滚动，搜索能过滤动作。
3. 分别切换单击、双击和长按，进入参数页后返回动作列表；最后用 Esc 和返回按钮关闭侧栏。检查断连和「减少动态效果」两种状态。
4. 在已授权的环境里切到目标 App，实际按键验证输出。只在设置窗口中看到模型高亮，并不能验证动作已发给目标 App。
