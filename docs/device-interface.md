# Rimo 设备界面

本文记录当前 macOS 主应用的设备首页和详情页。共享颜色和控件样式以 [`RimoStyle`](../Rimo/Settings/SettingsView.swift) 为准，设备布局、投影和命中区域分别由 [`MappingView`](../Rimo/Mapping/MappingView.swift) 和 [`RemoteModelView`](../Rimo/Mapping/RemoteModelView.swift) 实现。

## 首页与详情

- 首页展示静止的设备与投影。已连接时可点击进入详情，鼠标悬停不再移动遥控器；鼠标旁显示「点击进入」，尖端位置出现轻微扩散波纹。提示跟随鼠标，只在设备入口的命中区域内出现，移出、断连、窗口失去活动状态或进入详情时清除；提示层不拦截点击。键盘聚焦显示轮廓，未连接时灰显并禁用设备入口。
- 详情默认展示完整的 3D 遥控器，略向左转，空闲时轻摆并带绿色呼吸光。默认没有热点或标签，也可拖动模型查看。
- 点击模型上的按键后，相机推近按键区，保留所有可配置按键，部分下部握柄裁出画面。场景导航和电量状态向左滑出；全部按键沿实体形状显示轮廓，未分配时使用白色描边，分配了有效映射后使用主题色描边。当前键使用略粗的轮廓并显示短标签，标签颜色跟随映射状态。
- 点击模型上的另一个键可切换编辑对象，重复点击当前键继续编辑并保持前排。点左上角返回或按 Esc 收起动作侧栏并恢复全景。系统开启「减少动态效果」时直接切换状态，浏览时不摇摆或呼吸。
- 相机通过统一过渡状态逐帧更新，重复目标不重启动画，快速反向切换从当前进度接续。从详情页直接打开「添加应用程序」也进入前排；多选 App 时保持前排。从按键编辑进入添加栏保留相机位置，收起后恢复该按键的动作栏。
- 首页命中区域、电量位置与详情全景共用 `RemotePresentation.centerY` 的垂直基准，取消悬停和详情页原有的 12 点上移偏移。进入详情时设备不会额外向上跳动；前排相机继续使用自身的顶部留白。开启「减少动态效果」时保留文字提示和静态波纹，不持续扩散。

## 动作侧栏

侧栏贴窗口右侧、占窗口宽度三分之一并填满高度。灰色「动作」标题栏下方是搜索、推荐动作和可折叠的分类，不再单独放置触发方式切换区。每行动作右侧使用紧凑的触发控件：单击为一个圆点、双击为两个圆点、长按为短横。默认只显示当前符号，仅悬停符号按钮区域或键盘聚焦时展开全部三种方式（动作名称、整行和控件外的留白不触发展开），点击后选中底块滑到相应位置，移出时收拢为选中符号。已绑定使用主题色，未绑定显示灰色单击符号。系统开启「减少动态效果」时直接切换状态。

动作行下方不展开配置。录制快捷键、选择 App 或快捷指令等需要输入的动作使用单独配置窗口；普通动作可直接通过行尾符号绑定。推荐列表展示当前实体键的已配置动作，切换触发方式时保持行的位置。同一全局或 App 场景内，动作改绑会自动清除其他按键或触发方式上的旧绑定；场景继承的旧绑定会变为显式空值，防止回退和启动补齐重新恢复它。

「打开 App」的独立配置窗口包含「输入应用程序路径」和「浏览应用程序」。可粘贴完整的 .app 路径后按回车，或用从「应用程序」目录打开的 macOS 选择器。只有有效的应用程序才会替换当前映射。

侧栏布局参考 Logi Options+ 主应用；Rimo 保留自己的遥控器模型、推近动效和触发方式。参考行为和适配方式见 [Options+ 对照记录](optionsplus-main-findings.md)。

动作顺序为“推荐 → 键盘 → 媒体与音量 → 窗口与桌面 → 系统操作 → 应用与快捷指令 → 其他动作”。推荐根据实体键变化；键盘提供「键盘快捷键」、常用编辑操作和常见按键。「其他动作」里的「滚动模式」仅可绑定到非方向键，方向键编辑器会显示警告并禁用该选项。搜索框采用带完整边框的 48 点输入框，支持动作名、分类名和常用旧称。分类依据、Voxa/RemotePilot 对照和未实现能力见[动作映射清单](action-mapping-catalog.md)。

## 全局提示

改绑反馈、暂停／恢复、快捷指令结果和操作错误使用窗口顶部居中的胶囊提示，不在动作列表底部留出提示栏。提示使用短文案和一个轻量图标，成功或普通消息约 3 秒后自动消失，错误约 5 秒；点击可提前关闭，连续操作以最新消息替换旧消息并重新计时。详细原因保留在悬停提示与辅助功能标签中，开启「减少动态效果」时不滑动。

搜索上方不再显示遥控器麦克风说明；语音状态和安装入口集中放在设备设置。字段校验和必须由用户处理的系统授权继续保留在其操作位置。

## 回归检查

1. 以默认窗口（1200 × 720 点）和最小窗口（860 × 600 点）确认全景无标记，进入前排后检查全部 13 个按键轮廓，未分配为白色、已分配为主题色，实体按键可点击且轮廓与模型对齐，最低的键仍完整可见。
2. 验证左右区域不重叠：侧栏贴右且不盖住顶部设备入口；各分组可展开和收起，长列表可滚动，搜索能过滤动作。
3. 检查行尾控件的收拢、悬停展开、点击滑动、移出收拢和键盘聚焦。验证悬停不保存、切换触发清除旧绑定、跨按键改绑、场景隔离和重启后读回，列表下方不出现额外设置。验证快捷键和应用程序配置窗口的确认、取消、无效路径和旧映射显示。最后用 Esc 和返回按钮关闭侧栏；检查断连和「减少动态效果」两种状态。
4. 确认设备设置中的输入监控和辅助功能均为「已允许」。保持 Rimo 设置窗口在前台，实际按遥控器验证单击、双击和长按输出；再切到目标 App 验证场景映射。暂停映射或录制快捷键时应停止输出。模型高亮只说明按键被读取，执行日志只说明动作进入执行流程，最终效果需要在屏幕上确认。权限列表缺少 Rimo 或存在多个构建副本时，按 [README 的排查步骤](../README.md#权限列表中没有-rimo或映射没有效果)添加当前运行的应用。

添加应用程序使用按名称排序的连续列表，保留多选、顶部待添加图标和确认 / 放弃，点击 App 只切换选择。系统应用沿用确认的常用名单，其余可手动添加。
