# Rimo：功能范围与已知限制

Rimo 将 Apple TV Siri Remote 作为 Mac 的输入设备使用。目前以 **A2540** 为首要实测机型，配对由 macOS 系统蓝牙设置负责。

| 功能 | 当前实现与限制 |
| --- | --- |
| 设备界面 | 首页显示静态设备图、蓝牙状态和电量。详情页可旋转 3D 模型；选中按键后推近，描出键的轮廓并打开动作侧栏。未连接时设备灰显，入口不可点击。 |
| 按键映射 | 单击、双击、长按可分别映射到键盘快捷键、鼠标点击、四向滚动、媒体控制、系统操作、打开 App、输入文本和 macOS「快捷指令」。可停用单个触发或暂停全部映射。 |
| 按住至松开 | 单击或长按配置中的键盘快捷键可保持按下，直到遥控器松开。单击配置使用此模式时，同个键的双击和长按不会触发。 |
| 场景 | 开启自动切换后匹配前台 App，找不到已启用的场景时使用全局映射。手动创建的场景以全局映射的副本为起点，并为未设置的按键补齐通用单击动作；每套预设覆盖全部实体按键的单击映射。应用预设到已有场景更新全部单击映射，双击和长按继续独立配置。旧场景自动补齐缺失且未显式清除的单击映射，保留自定义动作与停用状态。 |
| 输入监听 | 目前使用被动监听；无法保证拦截 macOS 原按键动作。映射在任何窗口中都能执行，包括 Rimo 设置窗口；暂停映射或录制快捷键时不发送映射。其他遥控器机型尚未验证。 |
| 权限 | 输入监控用于读取按键，辅助功能用于发送键盘映射；蓝牙连接不代表这两项已获授权。权限列表缺少 Rimo 时可手动添加当前运行的 Rimo.app，授权后重启并在设备设置中确认「已允许」。部分系统将辅助功能入口显示为「设备控制和数据访问」。 |
| 电量 | 优先读取 macOS 配件电源信息，失败时回退到 HID。无法可靠区分设备或读不到电量时显示「电量未知」。 |
| 遥控器语音 | 实验功能。A2540 使用 PacketLogger 管道采集、后台 Opus 解码，支持尾包收尾、有限丢帧补偿及断连清理；需要额外的 Apple 工具。Siri 键映射成输入法语音快捷键（单独的修饰键）时才把声音送到虚拟麦克风；首次引导中输入一次管理员密码部署全部组件，之后自动运行。 |
| 虚拟麦克风 | 提供可安装、更新的「Rimo Remote Microphone」，包含读写诊断、连续分段尾音保留及设备失效后的重绑定。部署时重新加载 coreaudiod，无需重启；实时输出和唤醒恢复仍需真机验收。 |

应用设置保存在本机，遥控器音频只发送到虚拟麦克风，不保存录音。构建、配对、权限和实验性收音的说明见 [README](../README.md)；设备诊断见 [A2540 收音原型](../Rimo/Input/VoicePrototype/README.md)。
