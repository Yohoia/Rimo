# Rimo 动作分类与映射能力

核对日期：2026-11-17。参考本地 Voxa 2.2.1 Build 97 和 RemotePilot 1.1.5 的既有分析资料；本次未重新运行参考应用。Rimo 的能力以当前动作数据、配置界面和执行代码为准。

## 能力对照

| 映射能力 | Voxa | RemotePilot | Rimo 当前实现 |
| --- | --- | --- | --- |
| 键盘单键与组合键 | 支持，含左右修饰键 | 支持自定义快捷键 | 录制快捷键、选择特殊键、左右修饰键、Fn；常用单键可直接选择 |
| 按住与松开 | 短按和按住配置、保持按下 | 按住模式和自定义快捷键保持 | 键盘动作支持按住至松开；单击配置使用该模式时会接管双击和长按 |
| 多种触发 | 按键相关的短按、长按、双击 | 双击、长按和组合等 | 单击、双击、长按分别配置；未实现三击和多键组合 |
| 鼠标点击 | 左键、右键 | 左键、右键、双击、拖拽锁定 | 光标当前位置左键、右键、双击、中键；未实现拖拽锁定 |
| 滚动 | 音量键模式、外圈滚轮 | 四向滚动、触控与外圈模式 | 滚动模式让四个方向键在光标所在区域滚动；未实现触控和外圈手势 |
| 媒体与音量 | 系统媒体输出键 | 音量、播放、上一首、下一首等 | 播放/暂停、上一首、下一首、增大/减小音量、静音切换 |
| 窗口与桌面 | 通过快捷键和场景实现 | 系统动作及快捷键 | 调度中心、当前 App 全部窗口、显示桌面、前后桌面；依赖系统默认快捷键 |
| 屏幕与电源 | 熄屏、锁屏、系统睡眠等 | 含屏保等系统动作 | 锁屏、关闭显示器；未实现系统睡眠、关机、屏幕亮度 |
| 打开应用 | 场景中绑定 App | 系统自动化等路径 | 打开或切换至所选 App，全局和 App 场景均可绑定 |
| 文本输入 | 特定按键的文本加回车 | 自定义文本 | 已保存的文本映射仍可使用；新建动作时不再提供 |
| 自动化 | 直接运行 macOS 快捷指令 | AppleScript、Shell | 直接选择并运行 macOS 快捷指令；未实现独立脚本动作或多步骤宏编辑器 |
| 触控、外圈与语音 | 独立触控、外圈和语音能力 | 独立触控、外圈和语音能力 | 语音收音为独立实验功能；未实现触控移动、外圈切换或语音动作映射 |

## 侧栏分类

“推荐”始终位于顶部并展开。它按实体键推荐已有动作：方向键对应方向和翻页、返回键对应 Esc、播放和音量键对应媒体、中心键对应回车或空格、电源键对应锁屏或关闭显示器。当前映射也保留在推荐区顶部。

下方分类按以下顺序折叠显示：

1. **键盘**：自定义录制、复制、剪切、粘贴、撤销、重做、全选和查找。可直接选择回车、Esc、空格、Tab、退格、向前删除、Fn、左右 Command/Option/Control/Shift、Caps Lock、四个方向键、Home/End 和 Page Up/Down。字母、数字、符号及 F1–F20 可通过「自定义」录制。
2. **媒体与音量**：播放/暂停、上一首、下一首、音量和静音。
3. **窗口与桌面**：调度中心、App 窗口、显示桌面、前后桌面。
4. **系统操作**：锁定屏幕、关闭显示器、全屏截图、截屏工具栏、表情与符号。
5. **应用与快捷指令**：打开 App、运行快捷指令。
6. **其他动作**：滚动模式、网页前进/后退、新建及切换标签页、页面放大/缩小/重置。浏览与缩放动作通过 macOS 常用快捷键执行，前台 App 需支持对应操作。

「滚动模式」只能绑定到非方向键。为方向键选动作时，该项不可选，右侧显示警告。开启后四个方向键用于滚动，以同一方式再次触发可恢复原映射。也可从菜单栏关闭；暂停映射或断开遥控器会退出模式。

已保存的鼠标、单次滚动和文本动作仍可查看、执行和修改。
触发方式属于侧栏顶部的单击/双击/长按选择；场景决定映射生效范围，不作为动作分类。停用某次触发保留在动作配置中。Siri 键启用收音时由收音功能接管，不开放动作编辑。

搜索匹配动作名称及分类名称，展示相应分类下的结果，避免重复列出推荐项。搜索框参考 Options+ 主应用按键配置搜索的 80 点区域、16 点边距、48 点输入框和 4 点圆角；使用完整边框，聚焦时改为紫色，右侧搜索图标在输入后替换为清除按钮。

## Options+ 其他动作适配

核对本地 Options+ 2.9.1013853 编译组件 `components/app.min.js/44707/_0x32cc61.js` 的 `renderAllCardsDropDown`：标题“其他动作”对应筛选并排序后的 `allActionCards`，包含按设备能力和当前配置过滤的逻辑，并非所有设备完全相同的固定菜单。文案依据 `agent-resources/data/strings/zh-CN.yaml` 中的复制、剪切、粘贴、撤销、重做、前进/后退、新标签页、放大/缩小、缩放重置、截屏和表情符号等条目；本次未重新运行 Options+。

Rimo 从中选择适合实体键触发的通用编辑、浏览和系统工具动作，并补齐全选、查找与标签页前后切换。主分类之间每个动作只归属一处；推荐区仍可作为当前动作的快捷入口。
