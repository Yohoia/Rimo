# Rimo 动作分类与映射能力

核对日期：2026-11-17。参考本地 Voxa 2.2.1 Build 97 和 RemotePilot 1.1.5 的既有分析资料；本次未重新运行参考应用。Rimo 的能力以当前动作数据、配置界面和执行代码为准。

## 能力对照

| 映射能力 | Voxa | RemotePilot | Rimo 当前实现 |
| --- | --- | --- | --- |
| 键盘单键与组合键 | 支持，含左右修饰键 | 支持自定义快捷键 | 录制快捷键、选择特殊键、左右修饰键、Fn；常用单键可直接选择 |
| 按住与松开 | 短按和按住配置、保持按下 | 按住模式和自定义快捷键保持 | 键盘动作支持按住至松开；单击配置使用该模式时会接管双击和长按 |
| 多种触发 | 按键相关的短按、长按、双击 | 双击、长按和组合等 | 单击、双击、长按分别配置；未实现三击和多键组合 |
| 鼠标点击 | 左键、右键 | 左键、右键、双击、拖拽锁定 | 光标当前位置左键、右键、双击、中键；未实现拖拽锁定 |
| 滚动 | 音量键模式、外圈滚轮 | 四向滚动、触控与外圈模式 | 实体键触发上、下、左、右定量滚动，可调距离；未实现触控和外圈手势 |
| 媒体与音量 | 系统媒体输出键 | 音量、播放、上一首、下一首等 | 播放/暂停、上一首、下一首、增大/减小音量、静音切换 |
| 窗口与桌面 | 通过快捷键和场景实现 | 系统动作及快捷键 | 调度中心、当前 App 全部窗口、显示桌面、前后桌面；依赖系统默认快捷键 |
| 屏幕与电源 | 熄屏、锁屏、系统睡眠等 | 含屏保等系统动作 | 锁屏、关闭显示器；未实现系统睡眠、关机、屏幕亮度 |
| 打开应用 | 场景中绑定 App | 系统自动化等路径 | 打开或切换至所选 App，全局和 App 场景均可绑定 |
| 文本输入 | 特定按键的文本加回车 | 自定义文本 | 最多 4000 字符，可选输入后回车 |
| 自动化 | 直接运行 macOS 快捷指令 | AppleScript、Shell | 直接选择并运行 macOS 快捷指令；未实现独立脚本动作或多步骤宏编辑器 |
| 触控、外圈与语音 | 独立触控、外圈和语音能力 | 独立触控、外圈和语音能力 | 语音收音为独立实验功能；未实现触控移动、外圈切换或语音动作映射 |

## 侧栏分类

“推荐”始终位于顶部并展开。它按实体键推荐已有动作：方向键对应方向和翻页、返回键对应 Esc、播放和音量键对应媒体、中心键对应回车或鼠标点击、电源键对应锁屏或关闭显示器。当前映射也保留在推荐区顶部。

下方分类按以下顺序折叠显示：

1. **键盘**：自定义快捷键、输入文本，以及回车、Esc、空格、Tab、退格、四向方向键、翻页、Home、End。
2. **鼠标**：左键单击、右键单击、左键双击、中键单击。
3. **滚动**：向上、向下、向左、向右；进入后可调整距离。
4. **媒体与音量**：播放/暂停、上一首、下一首、音量和静音。
5. **窗口与桌面**：调度中心、App 窗口、显示桌面、前后桌面。
6. **系统操作**：锁定屏幕、关闭显示器。
7. **应用与快捷指令**：打开 App、运行快捷指令。

触发方式属于侧栏顶部的单击/双击/长按选择；场景决定映射生效范围，不作为动作分类。停用某次触发保留在动作配置中。Siri 键启用收音时由收音功能接管，不开放动作编辑。

搜索匹配动作名称及分类名称，展示相应分类下的结果，避免重复列出推荐项。搜索框参考 Options+ 主应用按键配置搜索的 80 点区域、16 点边距、48 点输入框和 4 点圆角；使用完整边框，聚焦时改为紫色，右侧搜索图标在输入后替换为清除按钮。
