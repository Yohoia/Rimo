## 对 Rimo 的建议，属于产品适配

1. 保持 Rimo 品牌和实时 3D；借鉴产品居中与顶部功能分组，不按图片的宽高参数机械缩小细长遥控器。
2. 图标 hover 用极浅紫底和明确 focus 环；有真实待处理内容时才显示提示点。
3. 通过模型上的短标签标明实体键，在动作侧栏中显示当前动作，提供搜索、可折叠分组和动作参数。
4. 场景沿用全局映射的动作配置能力，按当前 App 区分映射范围。
5. 保持 Rimo 的绿色连接光晕与断连灰显规则。

## 添加应用程序与场景

2026-11-18 实机核对「MX Anywhere 3S → 添加应用程序」及勾选 Safari 后的待确认状态。右侧栏标题为「选择应用程序」，说明为「为常用应用程序自定义按钮，提高效率。」；列表含已勾选的全局设置、可折叠的「预定义设置」「其他应用程序」和「添加其他应用程序」入口。勾选后显示「确认」「放弃」，顶部出现对应 App 图标。核对后点击放弃，本次未提交 Options+ 的配置。

应用专属配置对应 Rimo 的 App 场景；预定义设置对应场景预设。当前 Options+ 设备的预定义分组展示 Chrome、Excel、PowerPoint、Word 和 Safari，其他 App 也可建立应用专属配置。预定义分组只覆盖受支持的应用，不能推断每个 App 都有内置推荐动作。

Rimo 采用右侧三分之一宽、灰色标题区、勾选列表和确认/放弃流程，支持批量添加并在同一次配置保存中写入。预设复用 Rimo 已有动作：Keynote / PowerPoint 为演示翻页，Safari / Chrome / Firefox / Edge 可选长文阅读或网页视频，预览为长文阅读。选中时展示实际按键；网页视频注明 YouTube 播放器要求。这些 App 与预设的对应关系属于 Rimo 的产品适配。其他 App 延续手动场景的全局映射副本行为。顶部 App 图标选择编辑范围，场景是否自动生效由「场景」页的自动切换开关决定。
